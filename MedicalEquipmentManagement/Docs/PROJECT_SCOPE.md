# Phạm vi hệ thống

## Actor
- Guest: xem trang giới thiệu, đăng nhập.
- Staff: tra cứu thiết bị, xem chi tiết, nghiệp vụ kho/bảo trì theo quyền.
- Manager: toàn quyền CRUD + thống kê + quản lý người dùng.

## Bắt buộc theo học phần
1. MVC: Model – View – Controller.
2. Razor View + Layout + Partial View.
3. ViewBag/ViewData/ViewModel.
4. Form + Model Binding + DataAnnotations.
5. Session và (nếu chọn) Cookie.
6. Entity Framework + DbContext.
7. LINQ: tìm kiếm/lọc/thống kê.
8. CRUD dữ liệu.
9. Web API: GET/POST/PUT/DELETE.
10. Kiểm thử API.

## Tính năng đề xuất
- Đăng nhập/đăng xuất/phân quyền.
- Quản lý danh mục thiết bị.
- Quản lý thiết bị.
- Quản lý nhà cung cấp.
- Quản lý phòng ban.
- Nhập/xuất/chuyển thiết bị.
- Quản lý bảo trì.
- Tìm kiếm + lọc + sắp xếp.
- Dashboard thống kê.
- CRUD Web API cho thiết bị.
