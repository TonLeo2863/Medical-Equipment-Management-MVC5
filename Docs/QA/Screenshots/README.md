Các ảnh được chụp bằng Edge WebView2 trên BetaTest. Biểu mẫu trống khi chụp. Sidebar dùng danh tính ADMIN fixture.

| Ảnh | Nội dung |
|---|---|
| [Đăng nhập 390 px](rc-ui-390-dang-nhap.png) | Biểu mẫu đăng nhập và nút hiện mật khẩu. |
| [Menu 360 px](rc-ui-360-menu.png) | Ngăn điều hướng với các nhóm mở, có thể cuộn. |
| [Tạo tài khoản 360 px](rc-ui-360-tao-tai-khoan.png) | Biểu mẫu trên màn hình nhỏ và SVG cho trường vai trò. |
| [Tạo tài khoản 1280 px](rc-ui-1280-tao-tai-khoan.png) | Biểu mẫu có hướng dẫn và Sidebar desktop. |
